# Run From Here

This is the Flutter project root (contains pubspec.yaml). All Flutter commands must be run from this directory.

Examples:
- flutter pub get
- flutter analyze
- flutter test
- flutter run

If you are in the repository root, first:
- cd ai-tutoring-platform-5516-5525/ai_tutoring_app_frontend

Alternatively from repo root, use any of:
- ./flutterw analyze
- ./ci_run_flutter.sh analyze
- make analyze
- ./build.sh

Common error:
"Could not determine project root directory for Flutter project"
Fix:
Ensure your working directory is this folder before running Flutter.
