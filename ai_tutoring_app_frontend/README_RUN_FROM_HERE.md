# Flutter App Root

This directory is the Flutter project root for the AI Tutoring app.

Run Flutter commands from here to avoid:
> Could not determine project root directory for Flutter project

Common commands:
- flutter pub get
- flutter analyze
- flutter test
- flutter run

From the repository root, you can also use:
- ./ci.sh
- ./mobile_code_analysis.sh
- ./run_flutter.sh analyze
- ./flutterw analyze
