# flutterw (Flutter Wrapper)

Use this script at the repository root to run Flutter commands against the real app located at:
- ai-tutoring-platform-5516-5525/ai_tutoring_app_frontend

Examples:
- ./flutterw pub get
- ./flutterw analyze
- ./flutterw test
- ./flutterw run

This avoids "Could not determine project root directory for Flutter project" when tools start from the repository root.
