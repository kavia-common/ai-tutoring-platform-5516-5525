Repository Overview

This repo contains a Flutter app in a subdirectory.

Flutter app path:
- ai-tutoring-platform-5516-5525/ai_tutoring_app_frontend

Quick start:
- cd ai-tutoring-platform-5516-5525/ai_tutoring_app_frontend
- flutter pub get
- flutter analyze
- flutter test
- flutter run

Notes:
- The app implements an Ocean Professional themed AI Tutoring UI.
- Profile feature is integrated as the 4th bottom nav tab with routes:
  - /profile
  - /profile/edit
