# Contributing (AI Tutoring App Frontend)

Run all Flutter commands from this directory (the Flutter project root with pubspec.yaml).

Quick start:
- flutter pub get
- flutter analyze
- flutter test
- flutter run

If you are in the repository root, change into this directory first:
- cd ai-tutoring-platform-5516-5525/ai_tutoring_app_frontend

CI runners that start from repository root can use these wrappers:
- ./flutterw analyze
- ./ci_run_flutter.sh analyze
- make analyze
