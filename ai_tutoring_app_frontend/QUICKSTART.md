# Quick Start — AI Tutoring App Frontend

This is the Flutter project root (pubspec.yaml is here). Run all Flutter commands from this directory.

Commands:
- flutter pub get
- flutter analyze
- flutter test
- flutter run

From repository root, use one of:
- ./flutterw analyze
- ./ci_run_flutter.sh analyze
- make analyze
- ./build.sh
